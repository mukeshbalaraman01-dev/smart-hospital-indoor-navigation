# smart-hospital-indoor-navigation
MyBharat Hackathon Project

Problem Statement

Patients and visitors often find it difficult to locate departments, laboratories, consultation rooms, and emergency services inside large hospitals.

Proposed Solution

A smart indoor navigation system that helps users find hospital locations and follow simple indoor routes.

Key Features

- 2D indoor hospital map
- QR-code-based location assistance
- Bluetooth beacon positioning (planned feature)
- Search for departments and facilities
- Tamil and English support, with more languages planned
- Voice and vibration guidance for accessibility
- Hospital administration dashboard (planned feature)

Technology Stack

- Frontend: HTML, CSS, JavaScript (prototype)
- Backend and database: To be implemented
- Indoor positioning: QR codes; Bluetooth integration planned

Project Status

Proposal uploaded to GitHub. Prototype development is the next step.
